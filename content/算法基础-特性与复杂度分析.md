### 一、算法的特性

#### 1.1 正确性（Correctness）

算法满足问题要求，能正确解决问题。分 4 层含义：

- 程序不含语法错误
- 程序对几组输入数据能得出满足要求的结果
- 程序对精心选择的、典型、苛刻且带刁难性的几组输入数据能得出满足要求的结果
- 程序对一切合法的输入数据都能得出满足要求的结果


通常以第 3 层意义上的正确性作为衡量一个算法是否合格的标准。

#### 1.2 可读性（Readability）

- 算法主要为了人的阅读和交流，其次才是计算机执行 → 应易于理解
- 晦涩难懂的算法易隐藏错误且难以调试
#### 1.3 健壮性 / 鲁棒性（Robustness）

- 输入非法数据时，算法能恰当地做出反应或处理，而不是产生莫名其妙的输出
- 处理错误的方法不应是中断程序执行，而是返回一个表示错误（或错误性质）的值，以便在更高抽象层次处理
#### 1.4 高效性（Efficiency）

要求耗费尽量少的时间和尽量低的存储需求。

### 二、算法分析

#### 2.1 算法好坏的衡量顺序



一个好的算法首先要具备正确性，其次是健壮性、可读性；在这些都满足的情况下，主要考虑算法效率，通过效率高低判断不同算法的优劣。

#### 2.2 两个效率维度

||||
|---|---|---|
|时间效率|算法所耗费的时间|时间效率和空间效率有时候是矛盾的|
|空间效率|算法执行过程中所耗费的存储空间|需在两者间做取舍|


#### 2.3 时间效率的两种度量方法

||||
|---|---|---|
|事前分析|对算法所消耗资源进行估算|✅ 不依赖机器，可比性好|
|事后统计|将算法实现后测算时间/空间开销|❌ 花费较多时间精力；结果依赖软硬件环境，掩盖算法本身优劣|


#### 2.4 事前分析法

算法运行时间 = 一个简单操作所需的时间 × 简单操作次数，即每条语句执行时间之和：

算法运行时间 = ∑ 语句的频度 × 该语句执行一次所需的时间

- 语句的频度 = 该语句的执行次数
- 每条语句执行一次所需时间随机器而异（指令性能、速度、编译质量），由软硬件决定，与算法无关
- 因此假设每条语句执行时间为单位时间 → 讨论算法运行时间就转化为讨论所有语句频度之和
示例：n×n 矩阵相乘

```c
for(i=1; i <= n; i++)                        // n+1 次
	for(j=1; j <= n; j++) {                  // n(n+1) 次
		c[i][j] = 0;                          // n*n 次
		for(k=0; k < n; k++) {                // n*n*(n+1) 次
			c[i][j] = c[i][j] + a[i][k]*b[k][j]; // n*n*n 次
		}
	}
```

T(n) = 2n³ + 3n² + 2n + 1

但逐条统计太麻烦，只需比较它们的数量级。

### 三、渐进时间复杂度（大 O）

定义：若有某个辅助函数 f(n)，使得当 n 趋近于无穷大时，T(n)/f(n) 的极限值为不等于零的常数，则称 f(n) 是 T(n) 的同数量级函数，记作：

T(n) = O(f(n))

称 O(f(n)) 为算法的渐进时间复杂度（O = Order，表示数量级），简称时间复杂度。

矩阵相乘示例：T(n) = 2n³ + 3n² + 2n + 1，当 n → ∞ 时 T(n)/n³ → 2，故 T(n) = O(n³)。

核心思想：n 越大算法执行时间越长。它表示算法执行时间的增长率与 f(n) 的增长率相同。

#### n 的含义（问题规模）

|||
|---|---|
|排序|记录数|
|矩阵|矩阵的阶数|
|多项式|多项式的项数|
|集合|元素个数|
|树|节点的个数|
|图|图的顶点数|


#### 分析时间复杂度的基本方法

- 找出语句频度最大的那条语句作为基本语句
- 计算基本语句的频度，得到关于问题规模 n 的函数
- 取其数量级用「O」表示


简化规则：忽略常数项、去掉低次项、只保留最高次项（如 2n³ + 3n² + 2n + 1 → n³）。

### 四、分析案例

#### 案例 1：并列循环 → O(n²)

```c
x = 0; y = 0;
for (int k = 0; k < n; k++)
    x++;                    // O(n)
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        y++;                // O(n²)，取最大
```

取频度最大的语句：O(n²)。

#### 案例 2：两层循环（m×n）→ O(mn)

```cpp
void exam(float x[][n], int m, int n) {
    float sum[m];
    for (int i = 0; i < m; i++) {
        sum[i] = 0.0;
        for (int j = 0; j < n; j++)
            sum[i] += x[i][j];   // f(n) = m*n
    }
    for (int i = 0; i < m; i++)
        cout << i << ":" << sum[i] << endl;
}
```

基本语句频度 f(n) = m·n → O(m·n)。

#### 案例 3：三重循环 → O(n³)

```c
for (int i = 0; i < n; i++)
    for (int j = 1; j <= n; j++) {
        c[i][j] = 0;
        for (int k = 1; k <= n; k++)
            c[i][j] = c[i][j] + a[i][k] * b[k][j];  // O(n³)
    }
```

求和推导：

T(n) = Σᵢ₌₁ⁿ Σⱼ₌₁ⁿ Σₖ₌₁ⁿ 1 = Σᵢ₌₁ⁿ Σⱼ₌₁ⁿ n = Σᵢ₌₁ⁿ n² = n³ = O(n³)

#### 案例 4：三角循环 → O(n³)

```c
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++)
        for (int k = 1; k <= j; k++)
            x = x + 1;
```

内层次数 = 1 + (1+2) + … + (1+…+n) = O(n³)。

#### 案例 5：循环变量倍增 → O(log₂n)

```c
i = 1;              // （1）
while (i <= n)
    i = i * 2;      // （2）
```

关键：找出语句（2）执行次数 x 与 n 的关系：

|||
|---|---|
|1 次|2|
|2 次|2²|
|3 次|2³|
|x 次|2ˣ|


由循环条件 i ≤ n 得 2ˣ ≤ n，即 x ≤ log₂n，取最大值 f(n) = log₂n → T(n) = O(log₂n)。

### 五、小结

- 算法四特性：正确性 → 健壮性 → 可读性 → 高效性（前三个满足后再比效率）
- 时间效率与空间效率常常矛盾，需要根据场景取舍
- 分析复杂度只需关注数量级（大 O），忽略常数和低阶项
- 常见阶：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
- 循环分析技巧：




- 并列循环 → 相加取最大
- 嵌套循环 → 相乘
- 循环变量倍增（i*=2）→ O(log n)
