### 用途

改变文件或目录的访问权限。有两种用法：

- 文字设定法：包含字母和操作符表达式
- 数字设定法：包含八进制数字

### 一、文字设定法

chmod [who] [+ | - | =] [mode] 文件名

#### 操作对象 who

|||
|---|---|
|u|用户（user），文件/目录的所有者|
|g|同组（group）用户，与文件属主有相同组 ID 的用户|
|o|其他（others）用户|
|a|所有（all）用户（系统默认值）|


#### 操作符号

|||
|---|---|
|+|添加某个权限|
|-|取消某个权限|
|=|赋予给定权限并取消其他所有权限|


#### mode 权限字母

|||
|---|---|
|r|可读|
|w|可写|
|x|可执行|
|X|仅当目标文件对某些用户可执行或目标是目录时才追加 x 属性|
|s|执行时把进程属主/组 ID 置为文件属主（u+s 设置用户 ID 位，g+s 设置组 ID 位）|
|t|保存程序的文本到交换设备上（sticky bit）|
|u|与文件属主拥有一样的权限|
|g|与和文件属主同组的用户拥有一样的权限|
|o|与其他用户拥有一样的权限|


#### 示例

```bash
# 使同组和其他用户对文件 example 有读权限
chmod g+r,o+r example

# 属主加执行权限
chmod u+x script.sh

# 所有用户加读权限（等于 a+r）
chmod +r data.txt
```



文件名：以空格分开的要改变权限的文件列表，支持通配符；一个命令行可给出多个权限方式，用逗号隔开。

### 二、数字设定法

数字含义：0 无权限、1 可执行、2 可写、4 可读，权限值相加。

数字属性格式为 3 个 0~7 的八进制数，顺序为 (u)(g)(o)：

chmod [mode] 文件名

#### 权限数字速查表

|||
|---|---|
|0|---（无权限）|
|1|--x（执行）|
|2|-w-（写）|
|3|-wx（写+执行）|
|4|r--（读）|
|5|r-x（读+执行）|
|6|rw-（读+写）|
|7|rwx（读+写+执行）|


#### 示例

```bash
# 属主 读/写（4+2=6），组 读（4），其他 读（4）
chmod 644 file.txt

# 属主 全部权限，组和其他 读+执行
chmod 755 script.sh

# 属主 全部权限，组 读+写，其他 无
chmod 760 secret.dat
```



计算逻辑：rw- = 4(读) + 2(写) = 6。

### 三、常用权限速查（补充）

||||
|---|---|---|
|rw-r--r--|644|普通文件（默认）|
|rwxr-xr-x|755|脚本 / 目录|
|rwx------|700|私密文件（如 .ssh 私钥）|
|rwxr-x---|750|团队协作目录|
