### 一、简介

插入排序（Insertion Sort）是一种简单直观的排序算法。

核心思想：将待排序元素划分为「已排序」和「未排序」两部分，每次从「未排序」部分取出一个元素，插入到「已排序」部分的正确位置。

生活类比：打扑克牌时，从牌桌上抓一张牌，按牌面大小插到手牌的正确位置，再抓下一张牌 —— 就是插入排序。

### 二、算法步骤

以数组 [6, 5, 3, 1, 8, 7, 2, 4] 为例：

- 从第 2 个元素（下标 1）开始，假设第 1 个元素 [6] 已排序
- 取 key = 5，与已排序部分从右往左比较：6 > 5 → 6 后移，5 插入到位置 0
- 取 key = 3，6 > 3、5 > 3 依次后移，3 插入到最前
- …直到所有元素处理完

```
初始:   [6, 5, 3, 1, 8, 7, 2, 4]
第2轮:  [5, 6, 3, 1, 8, 7, 2, 4]
第3轮:  [3, 5, 6, 1, 8, 7, 2, 4]
第4轮:  [1, 3, 5, 6, 8, 7, 2, 4]
第5轮:  [1, 3, 5, 6, 8, 7, 2, 4]   ← 8 已在正确位置
第6轮:  [1, 3, 5, 6, 7, 8, 2, 4]
第7轮:  [1, 2, 3, 5, 6, 7, 8, 4]
第8轮:  [1, 2, 3, 4, 5, 6, 7, 8]   ✓ 排序完成
```
### 三、复杂度分析

||||
|---|---|---|
|最优时间复杂度|O(n)|数列几乎有序时，每个元素只需比较一次|
|平均时间复杂度|O(n²)|两层循环|
|最坏时间复杂度|O(n²)|逆序数列|
|空间复杂度|O(1)|原地排序（in-place），仅用常数辅助空间|
|稳定性|稳定|相同元素的相对顺序不变|
|适用场景|小规模 / 基本有序|常数因子小，实际速度可能快于 O(n log n) 的复杂算法（小 n 时）|


### 四、Go 代码实现

#### 4.1 原文实现（1 索引风格，对 a[1..n] 排序）

```go
func insertionSort(a []int, n int) {
	// 对 a[1],a[2],...,a[n] 进行插入排序
	for i := 2; i <= n; i++ {
		key := a[i]
		j := i - 1
		for ; j > 0 && a[j] > key; {
			a[j+1] = a[j]
			j--
		}
		a[j+1] = key
	}
}
```

#### 4.2 标准 0 索引 Go 实现

```go
func insertionSort(nums []int) {
	for i := 1; i < len(nums); i++ {
		key := nums[i]
		j := i - 1
		// 已排序部分从右往左扫描，比 key 大的元素后移
		for j >= 0 && nums[j] > key {
			nums[j+1] = nums[j]
			j--
		}
		nums[j+1] = key
	}
}
```

### 五、O(n²) 家族对比

|||||||
|---|---|---|---|---|---|
|插入排序|O(n²)|O(n)|O(1)|✅|基本有序时最快；常数小|
|冒泡排序|O(n²)|O(n)（优化后）|O(1)|✅|交换次数多，一般最慢|
|选择排序|O(n²)|O(n²)|O(1)|❌|交换次数最少（最多 n-1 次），但比较次数固定|


选型建议：

- 小规模（n < 50）或基本有序：插入排序是 O(n²) 中最优选择，甚至快于部分 O(n log n) 算法（如快速排序的小数组优化段）
- 大规模乱序：选快速 / 归并 / 堆排序
- 工程上（如 Go sort、Java Arrays.sort）常在快排/归并中对小数组回退到插入排序
