#### 1.8 经典编程题：二叉树层次遍历

已知：后序遍历 [2, 3, 1, 5, 7, 6, 4] + 中序遍历 [1, 2, 3, 4, 5, 6, 7]
求：层次遍历结果 [4, 1, 6, 3, 5, 7, 2]

结题思路（手写推导）：

- 由后序可知最后一个元素是根节点 → 4 是根
- 在中序中找 4 的位置 → 分两段：



- 左子树：[1, 2, 3]
- 右子树：[5, 6, 7]
- 由后序左子树段 [2, 3, 1] 可知左子树根为 1




- 1 在中序左子树最前 → 1 无左子树
- 左子树右部 [2, 3]，由后序 [2, 3] 知 3 是左子树的根
- 3 在中序位置 2 后 → 2 是 3 的左子节点
- 由后序右子树段 [5, 7, 6] 知 6 是右子树根


- 6 在中序右子树中部 → 5 是 6 的左子，7 是 6 的右子
- 层次遍历：根 → 左 → 右 = 4, 1, 6, 3, 5, 7, 2
得到的二叉树：

```
    4
   / \
  1   6
   \ / \
   3 5  7
  /
 2
```

字符串解码 LeetCode 394：

```go
func decodeString(s string) string {
    numStack := []int{}      // 数字栈
    strStack := []string{}   // 字符串栈
    num := 0
    cur := ""
    for _, c := range s {
        if c >= '0' && c <= '9' {
            num = num*10 + int(c-'0')
        } else if c == '[' {
            numStack = append(numStack, num)
            strStack = append(strStack, cur)
            num = 0
            cur = ""
        } else if c == ']' {
            n := numStack[len(numStack)-1]
            numStack = numStack[:len(numStack)-1]
            prev := strStack[len(strStack)-1]
            strStack = strStack[:len(strStack)-1]
            cur = prev + strings.Repeat(cur, n)
        } else {
            cur += string(c)
        }
    }
    return cur
}
```

func oddEvenList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    odd, even := head, head.Next
    evenHead := even
    for even != nil && even.Next != nil {
        odd.Next = even.Next
        odd = odd.Next
        even.Next = odd.Next
        even = even.Next
    }
    odd.Next = evenHead
    return head
}

#### 最少 bug 选码农

问题：n 个码农，每天 s[i] 行代码 + b[i] 个 bug；项目每天至少 m 行代码；选最少 bug 的集合

本质：0-1 背包问题的变形（约束 ≥ m，求最小代价）

解法：

DP：dp[i][j] = 前 i 个码农完成 j 行代码的最小 bug 数

状态转移：dp[i][j] = min(dp[i-1][j], dp[i-1][j-s[i]] + b[i])

答案：min(dp[n][j]) for j in [m, sum(s)]

- 

时间复杂度：O(n × sum(s))，可优化

#### 4.2 defer 顺序

```go
func main() {
    defer func() { fmt.Println(err) }()    // 第 3 执行
    defer func() { fmt.Println("a") }()   // 第 2 执行
    defer func() { fmt.Println("b") }()   // 第 1 执行
    panic("c")                              // panic: c
}
```

输出：

```
b
a
xxx        ← (panic 时 err 未赋值)
panic: c
```

核心规则：
- defer 在 return / panic 前执行
- defer 按后进先出顺序执行
- panic 之前的 defer 全部执行完毕后才真正 panic

func commonPrefix(a, b string) string {
    minLength := len(a)
    if len(b) < minLength {
        minLength = len(b)
    }
    sum := ""
    for i := 0; i < minLength; i++ {
        if a[i] != b[i] {
            return sum
        }
        sum += string(a[i])
    }
    return sum
}

#### 4.5 限制并发的请求处理（20 URLs / 5 goroutines）

核心模式：信号量（带缓冲的 channel）+ WaitGroup

```go
func NumberOfBytes(urls []string) int64 {
    control := make(chan bool, 5)        // 限流信号量，最多 5 个并发
    results := sync.Map{}                // 线程安全存储
    group := sync.WaitGroup{}
    group.Add(len(urls))

for i := range urls {
    go sendRequest(urls[i], control, &results, &group)
}
group.Wait()                          // 等待所有完成
close(control)

var sum int64
results.Range(func(url, count interface{}) bool {
    result := count.(int64)
    if result > 0 {
        sum += result                 // ⚠️ 修正：原来是 =+ 应为 +=
        return true
    }
    if result == -1 { fmt.Println("url请求失败") }
    if result == -2 { fmt.Println("body解析失败") }
    return true
})
return sum

}

func sendRequest(url string, control chan bool,
                 results *sync.Map, group *sync.WaitGroup) {
    control <- true                       // 占位
    res, err := http.Get(url)
    if res != nil {
        defer res.Body.Close()
    }
    <-control                             // 释放

if err != nil {
    results.Store(url, int64(-1))
    group.Done()
    return
}
all, _ := ioutil.ReadAll(res.Body)
if err != nil {                       // ⚠️ 应该是 ReadAll 错误
    results.Store(url, int64(-2))
} else {
    results.Store(url, int64(len(all)))
}
group.Done()

}
```

考点：
- 协程数量控制：缓冲 channel（信号量模式）
- 线程安全：sync.Map / 互斥锁
- 资源释放：defer Body.Close()
- 并发同步：sync.WaitGroup

#### 4.6 连接池设计

```go
type ConnPool struct {
    conns chan net.Conn
    factory func() (net.Conn, error)
}

func NewConnPool(size int, factory func() (net.Conn, error)) *ConnPool {
    return &ConnPool{
        conns: make(chan net.Conn, size),
        factory: factory,
    }
}

func (p *ConnPool) Get() (net.Conn, error) {
    select {
    case conn := <-p.conns:
        return conn, nil
    default:
        return p.factory()
    }
}

func (p *ConnPool) Put(conn net.Conn) {
    select {
    case p.conns <- conn:
    default:
        conn.Close()                      // 池已满，关闭连接
    }
}
```
